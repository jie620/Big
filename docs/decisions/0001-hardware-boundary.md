# ADR 0001: 硬件控制边界先使用 mock 传输

## 决策

`edgepick_hardware` 的第一版只接受六关节角度命令，并通过 `CommandTransport` 抽象发送。默认实现是内存 `MockTransport`，不会打开 I2C 设备，也不会移动机械臂。

`CommandGateway` 在调用传输层前执行：

- 关节范围和非有限浮点值校验；
- 100 至 30000 ms 的运动时间校验；
- 20 ms 最小命令间隔；
- 相同命令抑制；
- 可查询的接受、拒绝和传输失败计数。

## 背景

厂商 `Arm_Lib` 直接将 Python 调用映射为 SMBus 写操作，并只打印异常。厂商 ROS 驱动还会重复下发命令。EdgePick 应先把输入校验、限频与失败结果变成明确的 C++ 契约，之后再增加唯一的真实 I2C 适配器。

## 后果

当前包可在无相机、无机械臂的 CI 或开发环境测试。真实 I2C 适配器和 `ros2_control` 插件是后续独立阶段，接入时必须显式启用并验证系统中没有其他 I2C 写入者。
