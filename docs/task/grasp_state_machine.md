# EdgePick grasp state machine

阶段 4 的目标是先把抓取任务的控制逻辑做成可测试核心，而不是急着接相机、MoveIt 或真实机械臂。

## 状态

- `idle`：等待任务开始。
- `perceiving`：等待感知输出目标位姿。
- `planning`：等待 MoveIt 规划结果。
- `executing`：等待轨迹执行结果。
- `verifying`：执行后重新观察目标是否被拿走。
- `recovering`：执行换视角、重新定位、清理目标或安全退回等恢复动作。
- `succeeded`：任务成功终止。
- `failed`：恢复预算耗尽或恢复失败。
- `canceled`：用户或上层系统取消任务。

## 恢复策略

阶段 4 默认允许 2 次恢复尝试。以下事件会进入恢复：

- 感知目标丢失；
- 规划失败；
- 执行失败；
- 抓取验证失败；
- 感知、规划、执行、验证阶段超时。

恢复成功后回到 `perceiving`，重新感知目标；恢复失败或恢复超时直接进入 `failed`。
